# RAG 03 — Hybrid Search & Reranking

Covers why dense retrieval alone falls short and how to combine BM25 sparse retrieval with dense vectors using Reciprocal Rank Fusion (RRF) and score normalisation. Deep-dives into cross-encoder rerankers (BGE-Reranker-v2-m3, Cohere Rerank 3.5, mxbai-rerank-large-v1), ColBERT-as-reranker via PLAID, multi-stage cascade design, latency budget planning under 500 ms, and eval metrics (Recall@k, MRR, NDCG).
